I build things from scratch to learn how they work, from backend systems and low-level software to practical tools.

What I build

  • Backend systems and APIs that are clear and maintainable
  • Low-level software and operating systems
  • own versions of software that help me understand how systems work from the ground up

Selected projects

  • gluck-bot — Built an internal school assistant with persistent chat context, document sharing, and teacher workflows.
  • TetrOS — Built a bootloader and kernel for a playable Tetris OS, working on bare hardware and teaching me low-level fundamentals.
  • Voxel-Earth — A multiplayer voxel game where the real Earth is the world. It uses real-world elevation and land-cover data to generate a voxel representation of Earth.
  • VGL — Developed a Vulkan graphics library in C++ to learn about graphics programming and the Vulkan API, focusing on performance and low-level control.
  • Rasterization-Renderer — Implemented a 3D rasterization renderer in C++ and SDL, focusing on the math, pipeline, and performance tradeoffs behind real-time graphics.
  • IPL — Built an interpreter for a simple Python-like language with an emphasis on simplicity and clarity.

About the way I work

I learn by rebuilding things. The goal is not always to make the next best version, but to understand the ideas underneath it and turn that understanding into software that is direct, useful, and clear.

Based in Germany.
